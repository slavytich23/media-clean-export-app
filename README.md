# Media Clean Export

Windows GUI на PowerShell для обработки фото и видео через ExifTool, FFmpeg и FFprobe.

## Возможности

- профили Apple, Samsung, Google Pixel, Xiaomi, OnePlus, Sony, Motorola и Huawei;
- поиск профиля, избранные устройства и пользовательская марка/модель/объектив;
- запоминание последнего устройства, объектива, GPS и настроек обработки;
- выбранные Make, Model, LensModel и GPS применяются к фото и видео;
- галочка «Сохранить оригиналы и создать копии» работает для фото и видео;
- предпросмотр метаданных, таблица статусов, повтор ошибок и отмена после текущего файла;
- два режима видео: совместимый H.264/AAC или remux без перекодирования;
- резервная копия перед изменением фото на месте.

## Зависимости

Приложение автоматически ищет `ffmpeg.exe`, `ffprobe.exe` и `exiftool.exe` в следующем порядке:

1. `tools\ffmpeg\bin` и `tools\exiftool` рядом со скриптом;
2. известные локальные пути, если они существуют;
3. стандартный `PATH` Windows.

FFmpeg и ExifTool распространяются отдельно и имеют собственные лицензии.
Не добавляйте их бинарные файлы в этот репозиторий без проверки лицензий.

## Запуск

Запустите `Start Media Clean Export.bat`.

Перед обработкой:

1. добавьте файлы или папку;
2. выберите профиль и объектив;
3. проверьте GPS;
4. включите сохранение оригиналов, если нужны новые копии фото и видео;
5. выберите папку результата и режим видео;
6. нажмите «Начать обработку».

Фото при выключенной защитной галочке изменяются на месте. Перед этим приложение показывает предупреждение и может создать резервную копию.

## Проверка окружения

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\MediaCleanExport.ps1 -TestMode
```

Команда проверяет каталог профилей и доступность внешних инструментов, но не обрабатывает пользовательские файлы.

## Ограничения

- совместимый режим видео перекодирует материал и не является lossless;
- remux сохраняет потоки, но может быть несовместим с отдельными кодеками/контейнерами;
- дополнительные видеопотоки, субтитры и вложения не обещают сохранение;
- проект не предназначен для обхода анализа содержимого или правил площадок.
